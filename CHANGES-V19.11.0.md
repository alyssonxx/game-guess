# Game Guess V19.11.0 — Home Redesign

## Objetivo
Reorganizar a Home para reduzir poluição visual e deixar o fluxo mais claro no desktop e no mobile.

## O que mudou
- Hero principal simplificado com foco em "Jogar Agora" e "Arena Online".
- Remoção do excesso de banners e textos técnicos da tela inicial.
- Nova seção "Populares" com 4 entradas principais:
  - Game Guess
  - Quiz Mundial
  - KOF 2002 Magic Plus II
  - Termo Arcade
- Seção separada para os modos do Game Guess (`modeGrid`).
- Seção dedicada para Arena online, ranking e tutorial.
- Seção separada para universos extras (`universeGrid`).
- Barra de navegação inferior no mobile com atalhos rápidos.
- Topbar ajustada para ficar menos carregada.

## Arquivos alterados
- `index.html`

## Observações
- Nenhuma regra do KOF, Quiz, Termo ou Arena foi removida.
- A mudança foi focada na organização visual e experiência da Home.
- Os detalhes técnicos continuam nas telas internas, em vez de poluir a página inicial.
