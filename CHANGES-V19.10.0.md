# Game Guess V19.10.0 — Magic Plus II Native Specials

- Tabela DM / SDM(MAX) / HSDM(MAX2) refeita personagem por personagem com base na command list dedicada ao The King of Fighters 2002 Magic Plus II (Bootleg), GamesDatabase, 51 páginas.
- 44 personagens do catálogo têm um perfil primário para cada uma das três classes de super.
- Kula: Diamond Edge (DM), Freeze Execution (SDM/MAX) e Freeze Completion (HSDM/MAX2).
- MAX automático corrigido para B+C.
- Macros agora usam direções relativas (frente/trás), com opção LADO →/← para espelhar comandos quando o personagem cruza o adversário.
- Scripts especiais suportam sequências de botões, direções, espera e hold para golpes como Freeze Completion, Psycho Medley, Ecstasy 816, Super Black Hawk e Survivor's Banquet.
- Condições de distância/ar/transformação/contra-ataque são exibidas quando aplicáveis.
- ROM e backend/netplay não foram alterados por esta atualização.
