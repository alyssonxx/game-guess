# Game Guess V17.6 — Projeto consolidado

Esta pasta consolida as versões mais recentes entregues até a V17.6.

## Avatar / social
- Base V17 com avatar 3D estilizado, loja de personalização, amigos e convites.

## KOF 2002 Magic Plus II — V17.5
- EmulatorJS 4.2.1 / core arcade (FBNeo).
- PVP web / Netplay preservado.

## GeoGuess — V17.6
- Leaflet + OpenStreetMap.
- Sem dependência de Google Maps ou Mapillary.
- Exploração de mapa real sem nomes, mapa de palpite, distância e pontuação.
- `api/geoguess-map.js` consulta dados OSM/Overpass para a área da rodada.

## Observação
`api/geoguess-config.js` pode existir por compatibilidade histórica, mas não é necessário para o GeoGuess V17.6.
