# Auditoria V19.10.4 — KOF 2002 Magic Plus II

Fonte principal para DM/SDM/HSDM nativos: command list de 51 páginas específica do The King of Fighters 2002 Magic Plus II (bootleg) no GamesDatabase.

Fonte complementar para atalhos HSDM/MAX2: listas comunitárias de "ocultos" do Magic Plus. A V19.10.4 separa explicitamente comandos nativos de atalhos simplificados para não misturar as duas categorias.

Correções confirmadas nesta revisão:
- Iori DM: QCF + HCB + P (P = A ou C). Runtime tenta A e C.
- Iori SDM: QCF + HCB + A+C.
- Iori HSDM nativo: QCB + HCF + trás + frente + A+C; atalho MP2 usado pelo botão: U frente x2 + A+C.
- Yashiro Final Impact: QCB x2 + P; SDM: QCB x2 + A+C.
- Blue Mary M. Dynamite Swing: A, A, frente, B, C.

O runtime também passa a tratar P/K da command list como famílias de botão para DM, melhorando compatibilidade com revisões do hack e com o FBNeo.
